### Справочник модулей

Список и краткое описание ключевых модулей проекта. Будет пополняться автоматически по итогам анализа.

- backend/app/api — HTTP/WS обработчики
- backend/app/schemas — модели данных и схемы
- backend/app/prometheus — метрики
- common/app/core — конфигурация
- common/app/db — доступ к БД и инициализация
