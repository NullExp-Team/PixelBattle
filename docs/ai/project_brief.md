### Project Brief — PixelBattle-1

Цель документа: кратко описать назначение системы, ключевые компоненты, точки входа, данные и инварианты. Документ будет автоматически поддерживаться в актуальном состоянии на основе AST-анализа.

#### Назначение
Проект представляет собой backend с HTTP и WebSocket интерфейсами для интерактивного взаимодействия (Pixel Battle), с метриками Prometheus.

#### Ключевые компоненты (предварительно)
- backend/app/main.py — инициализация приложения
- backend/app/api/** — HTTP эндпоинты и WebSocket обработчики
- backend/app/schemas/** — модели данных/схемы
- common/app/core/config.py — конфигурация
- common/app/db/** — база данных и пул соединений
- Prometheus метрики и docker-compose для локального запуска

#### Точки входа
- HTTP: `backend/app/api/admin_login.py` (подключён), `admin_refresh_token.py` (не подключён)
- WS: `backend/app/api/web_socket.py` и `websocket_core/*`

#### Данные/БД
Описание моделей и таблиц будет уточнено после анализа `common/app/db` и `backend/app/schemas`.

#### Инварианты
- WebSocket авторизация и управление соединениями должны быть консистентны.
- Метрики Prometheus не должны деградировать производительность.
- Конфигурация не должна содержать секреты в коде.
- Инициализация БД не должна уничтожать данные на старте приложения.
