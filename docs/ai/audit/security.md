### Безопасность

Найденные проблемы:
- Секреты в коде: `SECRET_KEY`, `SECURITY_PASSWORD_SALT` (см. `common/app/core/config.py`).
- CORS: `allow_origins=["*"]` в продакшене (см. `backend/app/main.py`).
- Админские креды/логика логина захардкожены (см. `backend/app/api/admin_login.py`).
- Метрики доступны без ограничений (проверьте доступность `/metrics`).

Рекомендации:
- Хранение секретов в `.env`/Vault; ротация ключей; запрет печати конфигов.
- CORS по списку доверенных хостов, без `*`.
- Переписать админ-аутентификацию на БД/хэши + rate limiting.
- Ограничить доступ к `/metrics` сетью/ingress или basic-auth.
